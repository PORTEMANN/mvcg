# Incertitude et métrologie quantique

La métrologie quantique du SI n’est pas un capot D « conscience ».
C’est le raccordement de grandeurs à h, e, Δν_Cs.

## Calcul d’incertitude dans MVC-G (rappel)

GUM : lignes A/B → u_c → U = k u_c.
decide=theta : U informe. decide=U : U tranche.
Biais d’ansatz ≠ u_B.
S1 : tirage si f non linéaire et X_i vraiment incertains.
S2 : vecteur Y, région — seulement si S est vectorielle.

P20 : U table << δ. P27 : U << |E_corr|. H 1s : u(R_∞) ~ 10⁻¹², δ=0.

## Métrologie quantique (le métier réel)

Depuis 2019 :

- le kilogramme se rattache à h (balance de Kibble) ;
- l’ampère à e ;
- le kelvin à k_B ;
- la seconde reste Δν_Cs (horloge).

Effets utilisés : Josephson (V ~ hν/2e), Hall quantique (R_K = h/e²),
interférométrie atomique, horloges optiques.

Justesse *infra* : comparaison d’étalons, GUM + S2 (plusieurs sorties
corrélées : V, f, R).

## Ce que MVC-G peut peser là-dessus

Licite, calibre fin :

- identité R_K = h/e² dans un packet déclaré ;
- ν Josephson vs V/K_J avec K_J = 2e/h (exact depuis 2019) ;
- R_∞ vintage vs raie (déjà le geste H 1s).

Ce sont des **identités de définition** ou des écarts de réalisation
d’étalon — comme H 1s, pas comme P20.

## Ce qu’elle ne pèse pas

- la « quantification de la conscience » ;
- un S+ P20 comme raccord kilogramme ;
- n_e, n_γ du corridor comme constantes SI ;
- S2 sur (P20, P27) « parce que tout est quantique ».

Un étalon quantique a une chaîne vers h. Lowe n’en a pas.

## Phrase

L’incertitude MVC-G est un budget de dossier. La métrologie quantique
est une chaîne vers h et e. Elles se touchent sur les identités
(R_∞, R_K, K_J). Elles se séparent dès que le runner est un ansatz.
