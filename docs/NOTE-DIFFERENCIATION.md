# Note de différenciation — lecteur académique

**Ce dépôt (MVC-G) est un opérateur de verdict.**  
Il compare un nombre calculé ou lu à une cible déclarée, sous un seuil gelé, et rend S+, P ou S−. Rien d’autre.

## Ce qui appartient à ce dépôt

- un manifeste \(D\) (phrase \(S\), paquet d’unités, \(\theta\), levier) ;  
- une table vintage (fichier, pas un fetch) ;  
- des tueurs G1/G2 (antériorité, immutabilité) ;  
- des contacts de physique, chimie, cosmologie observationnelle et partitions discrètes, **un par ligne**.

Un S+ veut dire : l’écart tient dans *la* tolérance gelée.  
Il ne veut pas dire : la nature, l’esprit ou l’histoire des idées ont parlé.

## Ce qui n’appartient pas à ce dépôt

L’auteur a publié ailleurs un écosystème plus large (index.portemann.eu, corpus « Machine noétique » P0–P48, textes où la théosophie, la métaphore et la mesure cohabitent).

Cela a pu **inspirer** le geste « éprouver une structure ».  
Cela n’entre pas dans :

- le graphe d’appel (`src/mvcg/`) ;  
- le hash G1 ;  
- la phrase \(S\) d’un contact livré ici ;  
- l’interprétation d’un S+.

En particulier, **ne pas lire** dans MVC-G :

- une ontologie à trois registres du réel ;  
- une conscience, un « souffle », une cavité ANU, un pont vers \(E_8\) ;  
- une validation de doctrine théosophique ou religieuse ;  
- une unification physique–psychisme–cosmos.

Si un texte du web mélange ces genres, c’est **un autre document**. Le présent zip ne le charge pas.

## Règle de lecture

| Question | Réponse MVC-G |
|---|---|
| D’où vient l’idée ? | Hors protocole. Voir l’auteur, pas `D.json`. |
| Qu’est-ce qui est éprouvé ? | Uniquement ce qui est dans `D` + table + runner. |
| Un S+ confirme-t-il le reste de l’œuvre ? | Non. |
| Un S− réfute-t-il l’inspiration ? | Non plus. Il réfute *cette* phrase \(S\). |

## Pour citer

Citer **ce** dépôt pour le protocole de verdict et les contacts exécutables.  
Citer le dépôt d’archive historique de l’auteur (hors présent dépôt, sans
lien automatique) pour les chantiers P/A/M/E.  
Ne pas citer l’un pour les conclusions de l’autre.
