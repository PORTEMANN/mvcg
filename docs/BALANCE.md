# Tare et calibres

Sur une balance : on tare le plateau, puis on pose un jeu de poids.

- **Tare** — ôter le vide déclaré avant \(\delta\).
  - P20 : \(E(\mathrm{H})=-1/2\) (atomes séparés).
  - P27 HF : \(E_{\mathrm{HF}}\) (le déterminant). \(\mu=E_{\mathrm{HF}}-E_{\mathrm{HF}}=0\).
- **Calibre** — `fin` / `labo` / `grossier` : ordre de grandeur de \(\theta\), choisi *avant* le run.
  Changer de calibre après avoir vu le mot = autre \(D\).

Le calibre ne recalcule pas \(\theta\) tout seul (pas de S+ par changement de poids).
